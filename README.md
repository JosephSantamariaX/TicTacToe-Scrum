# TicTacToe Scrum Project

Este repositorio contiene la planificación de un proyecto de Tic-Tac-Toe utilizando el marco de trabajo Scrum.

## Scrum Roles

- **Product Owner**: Responsable de priorizar el Product Backlog y maximizar el valor del producto.
- **Scrum Master**: Facilita el uso correcto de Scrum y elimina impedimentos.
- **Equipo de Desarrollo**: Encargado de implementar las historias de usuario y entregar incrementos funcionales.

## Scrum Artifacts

### Product Backlog
Lista priorizada de todas las historias de usuario del proyecto.

### Sprint Backlog
Conjunto de historias seleccionadas para el Sprint actual.

### Increment
Resultado funcional del trabajo realizado durante el Sprint.

## Definition of Done (DoD)

Una historia de usuario se considera **Done** cuando:

- La funcionalidad está completamente implementada.
- Cumple todos los criterios de aceptación definidos.
- No presenta errores críticos.
- El código es funcional y estable.
- La historia puede considerarse potencialmente liberable.

## Sprint Execution

Durante el Sprint se seleccionaron historias desde el Product Backlog,
se trabajaron activamente en el Sprint Backlog y se entregó al menos un incremento funcional.
